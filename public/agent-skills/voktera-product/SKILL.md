# Voktera product

Voktera is a mobile-first personal dashboard:

- **Food** — meals, nutrients, ingredients, label scan
- **Gym** — workout plans, session logging
- **Tasks** — todos, repeats, goals

## URLs

- Marketing: https://voktera.com
- Web app (sign-in): https://app.voktera.com/login
- Changelog: https://voktera.com/changelog

## Auth

Email OTP via Supabase Auth on the app subdomain. See https://voktera.com/auth.md
